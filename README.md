# 아주오에이랜드 홈페이지

한국후지필름 비즈니스 이노베이션 정식대리점의 홈페이지 검토본입니다.

## 구성

- 홈 / 서비스소개 / 제품소개 / 설치사례 / 자료실 / 문의하기
- 반응형 화면, 제품·자료별 독립 주소, 서버에서 출력하는 본문과 메타데이터
- 공식 자료를 바탕으로 제품 6개, 자료실 10개 등록
- 사무기기·PC·네트워크 서비스용 AI 이미지 4장
- 문의 검토 화면과 접수번호, D1 문의 저장, 관리자 상태·메모·삭제 및 CSV 내보내기
- 관리자 글 작성·수정·삭제, 공개·임시저장, 검색 제목·설명 편집
- PDF.js로 첨부 PDF 첫 페이지를 WebP 썸네일로 생성, R2에 PDF와 썸네일 저장

## 설치사례·로그인·검색 개선 (2026-10-13)

- 관리자 로그인 화면 `/login`, 상단·모바일 메뉴 로그인 링크, 로그인 계정·로그아웃 표시
- 설치사례 목록·상세 페이지, 관리자 작성·수정·삭제·임시저장, 현장 사진 12장·대표사진·순서·설명
- 지역·모델·설치일·고객 환경, 최초 게시일·수정일, 검색·페이지 이동
- 게시판별 직접 작성·수정 링크, 자동 주소 버튼, 공개 주소 유지
- 개별 메타데이터·공유 이미지·BlogPosting·BreadcrumbList·사례/이미지 사이트맵
- Google·네이버 소유 확인 메타 태그용 환경변수 지원

사용 설명은 `docs/ADMIN_GUIDE.md`, 도메인·검색 검토 결과는 `docs/DOMAIN_AND_SEO.md`를 참고하세요. 글의 추가 정보는 기존 posts.data JSON에 저장하므로 DB 스키마 변경이나 기존 자료 재작성은 필요하지 않습니다.

## 관리자 사용

현재 Site 소유자의 ChatGPT 계정으로 `/admin`에 접속합니다. 서버에서 인증된 이메일을 `ADMIN_EMAILS` 허용 목록과 비교합니다. 다른 계정과 익명 사용자는 관리자 API에 접근할 수 없습니다. 외부 공개로 전환해도 이 검사는 유지됩니다.

1. 제품소개 또는 자료실 → 새 게시글
2. 제목·모델·분류·영문 주소·소개·본문 작성
3. PDF 첨부 → 첫 페이지 썸네일 생성 완료 확인
4. 공개 또는 임시저장 선택 → 게시글 저장
5. 문의 관리에서 접수 내용 확인 → 처리 상태와 내부 메모 저장

수정 화면을 닫으면 저장되지 않은 내용은 사라집니다. PDF는 암호 없이 20MB 이하를 사용합니다.

## 데이터와 접근

D1 `posts`, `inquiries`, `assets` / R2 `BUCKET`. 기존 seed 게시글은 DB의 변경 내용으로 덮어씌우며 삭제는 tombstone으로 처리합니다. 문의 내용과 임시 첨부 파일은 관리자만 조회합니다. 공개 게시글에 연결한 파일만 공개 조회할 수 있습니다. 접수 요청에는 동일 출처 확인, 필수값 검증, 개인정보 동의, 반복 접수 제한을 적용합니다. CSV 내보내기는 수식 실행 문자를 중화합니다.

환경 변수: `ADMIN_EMAILS`(secret), `SITE_URL`, `PUBLIC_INDEXING`, 선택 사항 `GOOGLE_SITE_VERIFICATION`, `NAVER_SITE_VERIFICATION`. 초기 검토본은 소유자 전용이며 `PUBLIC_INDEXING=false`로 검색엔진을 차단합니다. 실제 공개 전환 시 접근 설정·운영 도메인·검색 허용 설정을 함께 확인합니다. 도메인이 달라지면 `SITE_URL`을 변경하고 재배포하여 canonical과 사이트맵을 반영합니다. 기존 사이트 경로를 이전할 경우 별도의 301 리디렉션 매핑이 필요합니다.

현재 문의는 관리자 화면에 저장됩니다. 메일·문자 알림, 전자서명, 결제 기능은 포함하지 않습니다. 공개 운영 전 수집·이용 안내와 회사 정보의 최종 확인이 필요합니다.

## 자료 출처

확인일: 2026-10-12. 서비스 문구와 회사 정보는 https://ajuoaland.co.kr 의 인사말·임대/유지보수·오시는길을 기준으로 재구성했습니다.

제품 자료는 https://www.fujifilm.com/fbkr/ko 와 공식 카탈로그 도메인 https://asset-fb.fujifilm.com 에서 확인했습니다. 원문 링크는 각 게시글에 표시합니다. C3060/C2560/C3570의 현재 공급 여부는 확정하지 않았으며 제품 페이지에서 상담 확인을 안내합니다. 일부 PDF는 제품군 공용 문서입니다.

공식 지원: https://support-fb.fujifilm.com/setupSupport.do?cid=6&ctry_code=KR&lang_code=ko

`public/catalogs/*.pdf`는 제조사 원본, `public/images/catalog-*.webp`는 그 첫 페이지입니다. 제품소개·자료실의 표지와 사양에는 제조사 공식 자료를 사용합니다.

## 이미지

이미지 생성 도구 built-in image_gen을 사용했습니다. 2026-10-13 수정에서 메인과 사무기기 서비스 이미지를 FUJIFILM Apeos C3570 공식 사진을 참조한 AI 연출 이미지로 교체했습니다. 해당 PNG 원본은 `assets/source-images/`, 참조 사진은 `assets/reference-images/`, 웹용 WebP는 `public/images/`에 보존합니다. PC·네트워크 이미지는 각 서비스 장면을 사용합니다. 이후 서비스 사진의 용지함을 승인된 히어로와 같은 총 4개로 수정했고, 히어로 PNG·WebP는 바이트 단위로 그대로 보존했습니다.

생성 프롬프트와 참조 출처는 `image-prompts.json`, 이후 이미지 제작 기준은 `docs/IMAGE_GUIDELINES.md`를 확인하세요. 서비스 사진은 실제 직원·현장 사진이 아닌 설명용 AI 연출 이미지이며 공식 제품 사진이나 실제 설치·수리 사례로 표시하지 않습니다. 기존 1차 원본과 ZIP은 별도로 보관합니다.

## 검증

- TypeScript 검사와 프로덕션 빌드
- PDF.js 6.4.299로 공식 8페이지 PDF를 읽어 첫 페이지 708×1000 WebP 생성 확인
- `node tests/api.test.mjs`: SQL 마이그레이션을 적용한 인메모리 SQLite와 R2 mock으로 61개 assertions
- 게시글·설치사례 CRUD, 임시글·갤러리 비공개, 로그인한 비관리자 접근 차단, 동일 출처 검사, PDF/사진 저장·공개 상태, 검색 메타데이터·사이트맵·robots, 문의 필수항목·동의·상태·삭제·반복 접수 제한
- 브라우저 조작 도구를 사용할 수 없어 실제 브라우저/모바일에서의 시각 및 파일 선택 조작 검증은 수행하지 않았습니다.

## 로컬 명령

`pnpm exec tsc --noEmit` / `pnpm db:generate` / `node tests/api.test.mjs`

Sites 스킬의 설치·빌드·배포 워크플로우를 사용합니다. SQL 마이그레이션은 schema만 포함하며 기존 적용 파일은 수정하지 않습니다.
